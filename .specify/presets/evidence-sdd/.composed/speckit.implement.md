## Evidence Rules (evidence-sdd)

이 규칙은 위 지침에 추가로 적용된다. 위 지침과 충돌하면 이 규칙이 우선한다.

1. **검증 태스크는 실행 결과로만 완료한다**: 검증 태스크는 테스트를 작성한 것만으로 `[X]` 표시하지 않는다. 실제로 실행해서 기대한 결과(구현 전에는 실패, 구현 후에는 통과)를 확인한 뒤에 표시한다.
2. **구현 태스크는 연결된 검증이 통과한 뒤 완료한다**: 구현 태스크에 연결된 요구사항의 검증 대상이 통과하기 전에는 `[X]` 표시하지 않는다.
3. **추적표를 갱신한다**: 검증을 실행할 때마다 tasks.md의 `요구사항-검증 추적표`에서 해당 행의 상태(`통과` / `실패`)와 실행 근거(실행한 명령과 결과 요약, 예: `./gradlew test --tests PaymentConcurrencyTest` 3 passed)를 갱신한다.
4. **실행하지 못한 검증은 그대로 둔다**: 환경 문제 등으로 검증을 실행하지 못했으면 상태를 `미검증`으로 두고 이유를 실행 근거 칸에 적는다. 실행하지 않은 검증을 통과로 쓰지 않는다.
5. **완료 보고 기준**: 모든 태스크가 `[X]`여도 추적표에 `미검증` 또는 `실패` 행이 있으면 "완료"라고 보고하지 않는다. 보고에 추적표 상태별 개수와 남은 행 목록을 적는다.
