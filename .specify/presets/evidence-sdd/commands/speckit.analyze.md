
## Evidence Checks (evidence-sdd)

위 분석에 다음 점검을 추가한다. 결과는 위 지침의 Findings 표에 같은 형식으로 넣고, 아래 심각도를 따른다.

| 점검 | 확인 방법 | 심각도 |
|------|-----------|--------|
| 검증 없는 MUST 요구사항 | spec의 MUST FR / SC 중 tasks.md 추적표에 없거나 검증 태스크가 비어 있는 항목 | CRITICAL |
| 근거 표 누락 | spec의 FR / SC 중 `요구사항 근거` 표에 행이 없는 항목 | HIGH |
| 근거 없는 명시 / 관찰 | 출처가 `명시` / `관찰`인데 인용이나 위치가 비어 있는 행 | HIGH |
| 추정으로 확정된 MUST | 출처가 `추정`인 MUST 요구사항 중 research.md에 확인 근거가 없는 항목 | MEDIUM (보안, 결제, 데이터 보존 관련이면 HIGH) |
| 열린 질문 | research.md 질문 원장에서 `미해결` 또는 `부분 답변`인 질문 | `미해결`은 HIGH, `부분 답변`은 MEDIUM |
| 범위 없는 부재 주장 | research.md, plan.md에서 "없음", "영향 없음" 류 결론에 확인 범위가 없는 항목 | MEDIUM |
| 상태 불일치 | tasks.md에서 `[X]`인 태스크와 연결된 추적표 행이 `미검증` / `실패`인 경우 | HIGH |

Metrics에 다음을 추가한다.

- 출처별 요구사항 수 (명시 / 관찰 / 추정 / 미확인)
- 검증 연결률 (검증 태스크가 있는 MUST 요구사항 / 전체 MUST 요구사항)
- 질문 원장 상태별 수 (답변됨 / 부분 답변 / 미해결)
