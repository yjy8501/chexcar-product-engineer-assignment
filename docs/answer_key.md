# 정답표 (우리가 만든 해석)

회사가 준 정답이 아닙니다. 검수 메모 10건과 표준 코드표를 읽고 우리가 만든 해석입니다. 평가 결과는 "회사의 정답과 일치"가 아니라 "우리 해석과 일치"로 읽어 주세요. 기계가 읽는 형식은 `data/answer_key.json`입니다.

원칙: 문서(코드표, 메모)만으로 하나로 정할 수 없으면 확인필요입니다. 기본 문서에서 답을 찾지 못한 것은 아래 "문서에서 답을 찾지 못한 것"에 따로 모았습니다.

|---|---|---|---|---|---|---|
| INS-001 | 정상 | HD-00-RM(본넷 탈부착) 1개 | "프싸"가 어느 부위인지(FD-FR-SP 또는 BP-FR-PT) | 0 | | "탈부착 요망"은 지시이고 본넷이 분명하다. "프싸"는 문서에 없는 약어다 |

## 문서에서 답을 찾지 못한 것 (모두 확인필요로 처리)

| 질문 | 어느 메모 | 문서에 없는 이유 |
|---|---|---|
| "프싸"는 어느 부위인가 | INS-001 | 코드표와 메모에 설명이 없다 |
| 방향 없는 "휀다"나 "운전석 휀다"는 앞인가 뒤인가, 좌인가 우인가 | INS-003 | 코드표에 앞뒤와 좌우 코드가 따로 있고 운전석이 어느 쪽인지 설명이 없다. 우리 해석은 앞쪽 왼쪽(FD-FL-SP)이고 현장 확인이 필요하다 |
| 트레드 몇 mm부터 교환인가 | INS-006, INS-010 | 기준이 문서에 없다 |
| "1짝"은 타이어 몇 개인가 | INS-006 | 코드표 비고에 "1짝 기준"만 있다 |
| 일부 광택은 전체 광택 코드로 처리하는가 | INS-004, INS-020 | 코드표에 부분 광택 코드가 없다 |

문서에 해결 방법(용어집, 규칙)을 넣으면 풀리는 질문이지만, 그 해결 방법이 현장에서 맞는지는 사람이 확인해야 합니다. `knowledge/extended/`에 이 질문들의 가정을 담았고 점수에는 넣지 않았습니다.
